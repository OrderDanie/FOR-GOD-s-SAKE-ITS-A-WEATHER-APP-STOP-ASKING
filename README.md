Weather App
just a weather app. nothing fancy, nothing corporate. it works.

what it does
shows you the weather. current conditions, hourly forecast for the next day, seven day outlook. searches any city on earth. uses your location if you let it. saves your favorite spots so you don't have to type them again.

what you actually see
current temperature, what it feels like, humidity, wind speed and direction, pressure, cloud cover, uv index, visibility, dew point, rain chance, sunrise and sunset times. plus a day score out of ten so you know at a glance if it's worth going outside. hourly breakdown with rain probability for each hour. seven day cards with high low temps and rain chance. quick tips based on conditions - tells you to bring an umbrella, wear sunscreen, bundle up, whatever makes sense. moon phase, sun position, day length, golden hour times for photos. air quality index with pm2.5, pm10, ozone, nitrogen dioxide, sulfur dioxide, carbon monoxide. compares today to seasonal averages so you know if this is normal or weird. dark mode toggle. celsius fahrenheit switch. keyboard shortcuts - press s to search, l for location, u for units, d for dark mode, f for FU-, uhm, i mean favorites. share button copies a text summary to clipboard. works offline after first load as a pwa. tho it wont predict, so dont be mad if it rains, its not my fault vro.

how to use it
open index.html in a browser. that's it. no install, no build step, no node modules, no package.json. type a city name, wait a split second, pick from suggestions. or hit the search button. click the location pin to use gps. click the star to save current location to favorites. click a favorite to load it. click the moon/sun icon to toggle dark mode. click the c/f button to switch units.

what makes it work
html for structure. css for styling - gradients, animations, responsive grid, dark mode via css variables. vanilla javascript - no frameworks, no dependencies, no build tools. open-meteo api for weather, geocoding, air quality - completely free, no api key, no rate limits that matter for personal use. browser geolocation api for finding you. localstorage for favorites and preferences. service worker for offline caching.

data you get
temperature and feels-like. weather condition with emoji. humidity percentage. wind speed in km/h or mph, direction as compass bearing. pressure in hpa. cloud cover percentage. uv index with risk level. visibility in km or miles. dew point. precipitation probability. sunrise sunset times. moon phase with illumination percentage. sun elevation and azimuth. day length. golden hour and blue hour windows. air quality index with six pollutant readings. seasonal average comparison for temperature and rainfall.

privacy
no tracking. no analytics. no cookies. no accounts. no api keys stored. your location never leaves your browser - it goes straight to open-meteo for weather data. favorites stay in your localstorage. that's it.

files
index.html - single page, semantic html, meta tags for pwa styles.css - all styling, css variables for theming, mobile first responsive app.js - all logic, fetch, render, utils, event handlers manifest.json - pwa manifest for install prompt sw.js - service worker for offline caching README.md - this fil

browser support
anything from the last few years. chrome, firefox, safari, edge. mobile browsers work fine. needs javascript and internet for the first load.
